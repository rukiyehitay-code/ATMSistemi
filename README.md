# ATM Sistemi 

C# programlama dili ile geliştirilmiş, temel ATM işlemlerini gerçekleştiren konsol uygulaması.

## Özellikler

* Kullanıcı adı ve PIN ile giriş
* 3 PIN deneme hakkı
* Bakiye görüntüleme
* Para yatırma
* Para çekme
* Kullanıcılar arası para transferi
* İşlem geçmişi görüntüleme
* Geçersiz tutar kontrolü
* Yetersiz bakiye kontrolü
* Kendine para transferini engelleme
* `List<T>` kullanımı
* Class ve Object kullanımı
* Constructor kullanımı

## Kullanılan Teknolojiler

* C#
* .NET
* Visual Studio
* Git & GitHub
