# ATM Sistemi

C# programlama dili ile geliştirilmiş, konsol üzerinden temel bankacılık işlemlerinin gerçekleştirilebildiği bir ATM uygulamasıdır. Kullanıcı girişinden para transferine kadar çeşitli ATM işlemleri gerçekleştirilebilir ve işlemler işlem geçmişinde tutulabilir.

## Özellikler

* Kullanıcı adı ve PIN ile giriş
* 3 PIN deneme hakkı
* Bakiye görüntüleme
* Para yatırma
* Para çekme
* Kullanıcılar arası para transferi
* İşlem geçmişini görüntüleme
* Geçersiz tutar kontrolü
* Yetersiz bakiye kontrolü
* Kendine para transferinin engellenmesi
* Gönderen ve alıcı işlem geçmişlerinin tutulması
* Menü üzerinden işlem seçimi
* Çıkış işlemi
